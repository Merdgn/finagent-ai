
# FinAgent AI

Secure Banking Conversational AI Assistant

## Overview

FinAgent AI is an experimental AI engineering project
focused on building secure, context-aware conversational
experiences for banking information.

## Planned Technologies

- Python and FastAPI
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLMs)
- LangGraph
- Vector Search
- Docker and Pytest

## Current Status

Phase 1: Backend foundation and automated tests.

## Disclaimer

This project is an independent portfolio project.
It is not affiliated with TEB or any financial institution.
Only synthetic or publicly permitted sample data will be used.

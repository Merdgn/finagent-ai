# FinAgent Demo - Savings Account

Document Type: Product Information
Product: Demo Savings Account

## Overview

The Demo Savings Account is a fictional banking
product created for testing FinAgent AI.

## Account Opening

Customers can request account opening through
a digital onboarding process.

Identity verification is required before
account activation.

## Interest Rates

The interest rate is not fixed in this
demonstration document.

Users must refer to the current official
product disclosure for real banking rates.

## Withdrawals

Customers can request withdrawals subject
to account verification and applicable limits.

## Security

Account information must not be disclosed
without proper authentication.

## Disclaimer

This document contains fictional product
information for software testing only.
